# Routine Tracker

Учебный веб-сервис для учёта дел, занятости, дедлайнов и времени.

## Описание
Проект собирает данные о времени, которое люди тратят на базовые дела (сон, дорога, работа, отдых), и на их основе строит реалистичное расписание.

## Этапы
1. Сбор информации (Google Forms)
2. Анализ данных и графики
3. Разработка веб-сервиса
4. Хостинг
5. Презентация и защита
